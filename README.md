# Biodiversity Data Analysis

An independent statistical analysis project using R to investigate ecological datasets and explore relationships between environmental and biological measurements.

## Overview

The project involved analysing five ecological datasets containing over 600,000 observations. Each dataset was investigated through individual R analyses, applying statistical techniques to identify patterns, assess relationships and evaluate the suitability of statistical models.

## Methods and Techniques

- **Data preparation:** Filtering, reshaping and organising datasets for analysis.
- **Exploratory data analysis:** Examining distributions, patterns and relationships between variables.
- **Correlation analysis:** Measuring the strength of relationships between variables.
- **Linear regression:** Fitting and comparing regression models to investigate relationships between ecological measurements.
- **Model diagnostics:** Using residual plots to assess model fit and identify potential issues.
- **Data quality assessment:** Identifying outliers, anomalous measurements and potential sources of error.
- **Model refinement:** Investigating the effects of filtering observations and considering alternative approaches where linear models provided a poor fit.
- **Data visualisation:** Producing plots to communicate patterns and statistical findings.

## Example Analysis: Woodland Vegetation

One analysis investigated the relationship between tree height and diameter across multiple woodland sites.

This involved:
- Preparing tree measurement data by filtering and reshaping the original dataset.
- Fitting linear regression models to the combined data and individual sites.
- Comparing correlations and regression relationships across sites.
- Examining residual plots to assess model assumptions and identify potential problems.
- Investigating outliers, small sample sizes and possible non-linear relationships.
- Refining models through data filtering and comparisons of subsets.

## Technologies

- **R** – data manipulation, statistical modelling and visualisation
- **R Markdown** – combining analysis, code and written interpretation
- **ggplot2, dplyr and tidyr** – data manipulation and visualisation
